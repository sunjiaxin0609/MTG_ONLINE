# MTG Online UI 深色化与自适应改版 · 设计规格

- 日期：2026-10-04
- 范围：`mtg/ui/` 全部界面层（引擎、卡池、AI 均不改动）
- 目标：显示更明确、操作更舒服

---

## 1. 背景与问题

现有 UI 为浅色（米白牌桌）固定尺寸布局，经实机截图与代码审查，确认以下四类问题：

1. **状态与提示不明确**
   - 顶部只显示零散信息，当前回合数与阶段不醒目。
   - 手牌不可出的牌没有原因提示，`can_cast` 已返回的失败原因被 UI 丢弃。
   - 日志单色且用 `Consolas` 渲染中文，可读性差。
2. **明确的交互 bug**
   - [app.py](file:///c:/Users/wanxiaoxiao/Desktop/mtgo/mtg/ui/app.py#L692-L693) 中"不阻挡"按钮错误绑定 `self._confirm_blockers`，会误提交已分配的阻挡。
   - `_tap_for_mana` 只取第一个产费异能，多色地产费无法选色。
3. **操作手感**
   - 无快捷键，所有确认/放弃都要点按钮。
   - 非法操作弹 `messagebox`，打断节奏。
   - 结束回合/结束阶段入口不清晰。
4. **空间与卡牌尺寸**
   - 硬编码区域高度（header 38 / 右栏 300 / 两个战场各 200 / 中条 76 / 手牌 192 / 操作条 46）不随窗口变化。
   - 卡牌固定 104×146，窄窗口溢出、宽窗口浪费。
   - `CardStrip` 仅按固定尺寸算列数，不随窗口挑尺寸档。

---

## 2. 设计方向（已与用户确认）

- **视觉风格**：深色牌桌（MTGO / Arena 观感）。
- **尺寸策略**：自适应 —— 窗口尺寸决定卡牌尺寸档与列数。
- **实施方式**：分三阶段（地基 → 信息层 → 交互层），每阶段完成可先试玩。
- **文件结构**：拆分 UI 层为 4 个新模块，`app.py` 只留组装与引擎推进。

| 颜色 | 色值 | 颜色 | 色值 |
|---|---|---|---|

### 3.3 状态色

| 状态 | 色值 |
|---|---|
| 选中 | `#d8a84e` |
| 攻击中 | `#e0604a` |

### 3.4 字体

- 正文族：`Microsoft YaHei`（避免中文用 Consolas 渲染）。
- 等宽族（仅用于数字/费用）：`Consolas`。
- 字号：
  - `FONT_SMALL = (FONT_FAMILY, 8)`
  - `FONT_NORMAL = (FONT_FAMILY, 9)`
  - `FONT_BOLD = (FONT_FAMILY, 9, "bold")`
  - `FONT_TITLE = (FONT_FAMILY, 11, "bold")`
  - `FONT_LOG = (FONT_FAMILY, 9)`（由 `(Consolas, 8)` 改为雅黑 9）
  - 新增 `FONT_PROMPT = (FONT_FAMILY, 12, "bold")` 用于操作条主提示

`theme.py` 保留原有常量名（`BG / PANEL / PANEL_DARK / BORDER / TEXT / TEXT_DIM / CARD_BG / CARD_BORDER / COLOR_HEX / ACCENT / SELECTED / ATTACKING / BLOCKING / TAPPED / HIGHLIGHT / BTN_*`）与 `color_key()`，仅替换取值并新增少量常量，避免 UI 层其它文件大改。

## 4. 布局与自适应

### 4.1 窗口

- 启动尺寸：`min(1400, 屏宽 - 80) × min(900, 屏高 - 80)`。
- `minsize(1024, 700)`。
- 窄窗口（宽 < 1200）时右侧日志栏可折叠。

### 4.2 垂直布局权重

按权重分配，并夹在各自最小/最大值之间：

| 区域 | 权重 | 最小 | 最大 |
|---|---|---|---|
| 顶部回合·阶段条 | 固定 | 40 | 40 |
| 对手战场 | 3 | 140 | 320 |
| 中条（信息＋阶段控制） | 固定 1.6 估算 | 72 | 120 |
| 我方战场 | 3 | 140 | 320 |
| 手牌区 | 2.4 | 150 | 260 |
| 操作条 | 固定 | 44 | 44 |

实现方式：`board_frame` 网格化（`grid` + `rowconfigure(weight=...)`），固定条用 `grid_propagate(False)`。

### 4.3 卡牌尺寸阶梯

四档，按可用宽度选最大适配档：

| 档 | 卡牌 W×H | 图区 W×H |
|---|---|---|
| S | 84×118 | 80×112 |
| M | 100×140 | 96×134 |
| L | 116×162 | 112×156 |
| XL | 132×184 | 128×178 |

选档规则：给定容器可用宽度 `avail` 与列数上限，取满足 `columns × (W + 4) ≤ avail` 的最大档。列数 = `max(1, avail // (W + 4))`。

`CardWidget` 由固定类属性改为实例尺寸：`CardWidget(master, data, size=("M"))`，内部按档设置 `width/height`，同时把 `PIC_W/PIC_H`、`wraplength`、徽章位置改为按档计算。滚轮转发行保留。

### 4.4 图片缓存

`images.py` 的 `_photos` 键已含 `(token, w, h, dim)`；尺寸档增加后缓存条目变多，需加**每档缓存上限 + LRU 淘汰**（上限 300 条），避免内存膨胀。`peek` 仍不联网。

## 5. 信息层（阶段 2）

1. **顶部回合·阶段条**
   - 左侧：`第 N 回合 · 我方` / `对手`（我方蓝、对手红）。
   - 中部：当前阶段名，70/30 分割（左侧回合信息 70%，右侧阶段 30%）。
   - 当前阶段用金色 `#d8a84e` 高亮。
2. **不可出牌原因角标**
   - `_is_playable` 由 `-> bool` 改为 `-> tuple[bool, str]`，保留 `can_cast` 的 `reason`。
   - 手牌中不可出的牌右下角显示小角标（如"法术力不足"/"需法术时机"/"已横置"），悬停时 tooltip 显示完整原因。
3. **日志分类着色**（不修改引擎）
   - 按行首关键词正则分类：回合头 `#d8a84e`、阶段 `#8d97a5`、施放/加入堆叠 `#4d9fe0`、结算 `#e8ebf0`、触发 `#a583d8`、战斗 `#e0604a`、错误/警示 `#e0604a`。
   - 字体改为 `FONT_LOG`（雅黑 9）。
4. **状态栏拆分**
   - 卡池/卡图信息固定到顶部右侧。
   - 套牌信息（套牌名、颜色、剩余牌库）下移到中条信息区。

## 6. 交互层（阶段 3）

1. **快捷键**
   - `空格`：让过 / 结束当前阶段。
   - `Enter`：确认当前待选（攻击者/阻挡者/目标）。
   - `Esc`：清除当前选择 / 取消。
   - `A`：全选可攻击者。
   - `Ctrl+Enter`：结束本阶段。
   - 焦点在输入型控件时快捷键不触发。
2. **操作条重做**
   - 左侧：主提示（`FONT_PROMPT` 12px）说明当前需要做什么。
   - 中间：上下文按钮（按 `Decision.kind` 动态）。
   - 右侧：当前可用快捷键提示（灰色小字）。
3. **非法操作反馈**
   - 去掉 `messagebox`，改为操作条内红色提示，2 秒后自动消失（`after` 定时）。
4. **产费选色**
   - `_tap_for_mana`：若该永久物有多个产费异能/多色选择，弹轻量菜单（`tk.Menu`）让用户选色；单一产费直接产。
5. **修复"不阻挡"bug**
   - 新增 `_declare_no_blockers`：清空阻挡分配后提交空阻挡声明，不再复用 `_confirm_blockers`。

## 7. 文件结构（拆分）

| 新文件 | 职责 | 依赖 |
|---|---|---|
| `mtg/ui/layout.py` | 纯函数：窗口尺寸、区域高度、卡牌尺寸档与列数计算 | 无（只依赖常量） |
| `mtg/ui/board.py` | 牌桌渲染 + `CardStrip`（自动换行＋滚动＋选档） | `theme` / `card_widget` / `layout` |
| `mtg/ui/log_panel.py` | 日志面板：分类着色、追加、自动滚动 | `theme` |
| `mtg/ui/dialogs.py` | 所有弹窗：新游戏、卡图查看、区域列表、游戏结束、scry/surveil | `theme` / `images` / `carddb` |
| `mtg/ui/app.py` | 只保留：组装、引擎推进（`pump`/`_on_engine_log`）、决策分发 | 以上四者 |

目标：`app.py` 由 1162 行降到约 400 行；`layout.py` 为纯函数便于单测。

不改动：`mtg/engine/**`、`mtg/data/**`、`tests/ui_shot.py`（继续作为验收截图工具）。
